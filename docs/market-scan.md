# 市场扫描

侧栏入口「市场扫描」，地址 `#/market-scan`。参考 [88AI 市场页](https://88aitou.com/market) 的指数概览、特色榜单、股票查找与板块入口，按本项目数据能力提供 A 股版本。

## 功能与口径

- 指数概览复用境内指数快照；特色榜单包含涨幅、跌幅、成交额、换手率。
- 按名称/代码、最低/最高价格、最低涨幅、最低成交额（亿元）、最低换手率（%）及排除 ST 过滤。条件在当前榜单或板块返回样本上执行，不另扫全市场，不按拼音查询。缺失指标不满足对应的数值条件，真实零值仍为零；价格范围倒置、负价格或负成交额等条件明确报错。
- 行业/概念列表可切换，点击板块查看其成分返回样本。股票可打开现有个股详情；显式历史模式禁用该跳转，避免混入实时个股数据。
- 数据缺失或取数失败明确提示，不提供未经接入的实时热度、高股息及海外市场榜单，也不从现有样本推算这些排行。

## 数据与存储

直接复用 `dashboard.get`、`sector.stocks` 和已有 Provider，因此沿用其数据源优先级、熔断、缓存和部分返回行为，不新增行情接口或全市场逐股请求。榜单、板块及指数各自保留真实来源和时间，在面板头说明。单个区块失败保留其原样本及时间并标记过期；板块刷新失败同样保留已有成分。

成功请求由已有 Host `archiveMarketDashboard` / `archiveMarketPanel` 归档，复用统一 `MarketHistoryStore` 的 `overview`、`industry`、`concept`、`rank.*` 与 `sector:<code>`，不新建扫描快照表。扫描只是这些记录的派生视图，筛选条件本身是页面状态，刷新页面后重置。

休市进入页面时先读最近相关归档，分别检查上述七个面板及境内指数是否覆盖最近应收盘工作日。完整则不取实时数据；缺失/未收盘数据继续取数，读取归档失败明确提示。时间判断复用项目工作日策略，不声称是完整节假日历。

显式选择日期仅从所选本地归档读取，停止轮询；没有保存的榜单、板块或成分明确提示，不补实时数据。新取数据自动归档；清理行情缓存不删历史。日期/板块切换中止旧请求，迟到的响应不能覆盖新视图。

## 刷新与验证

开市使用统一 `isMarketOpen` 每 30 秒轮询，失败保留已有行，后台更新不卸载整个页面。手动「刷新样本」保留 60 秒冷却；自动轮询不读取手动冷却。历史视图禁止手动刷新行情。板块成分随成功的榜单更新刷新，历史及默认已完整休市归档中的成分仅本地读取。

组件测试覆盖筛选、缺失值、部分失败保留、手动冷却与自动轮询解耦、休市完整归档、显式历史只读及迟到响应。界面预览使用明确标记的示例数据；真实行情源可用性需在运行中的 Profile 核实。仅前端改动，构建后刷新工作台即可，无需重装 Profile。
